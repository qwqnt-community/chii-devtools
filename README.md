# chii-devtools

qwqnt/LiteLoaderQQNT 插件，使用 Chii 进行远程调试  
使用上跟普通的 DevTools 差不多，但缺失了一些功能

## 安装方法

### 通过 Release

下载最新的 `Release` 的 `chii-devtools.zip`，解压到 `chii-devtools` 放到 `插件目录`

### 通过 Clone

> [!NOTE]\
> 该项目使用的chii依赖为修补版本，如果想要修改这部分内容请到 [chii](https://github.com/xiyuesaves/chii), [chii-devtools-frontend](https://github.com/xiyuesaves/chii-devtools-frontend) 处查看

安装之前请先确保已安装 `Node.js`，能够使用 `pnpm` 工具

- 克隆/下载本项目，并将其放到插件目录下
- 进入本插件的目录内，执行命令 `pnpm install`
